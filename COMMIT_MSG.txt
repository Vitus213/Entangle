feat: 实现完整的 RBAC 权限管理系统

实现了基于角色的访问控制（RBAC）系统，包含用户认证、授权和权限管理的完整功能。

## 核心功能

### 1. 认证系统 (auth crate)
- JWT token 生成和验证
- Argon2 密码加密
- 权限检查服务 (PermissionService)
- 支持多种权限验证方式（单个、任意、全部）

### 2. 数据库层 (db crate)
- 新增用户、角色、权限的数据模型
- 实现完整的 Repository 模式
  - UserRepository: 用户 CRUD 和查询
  - RoleRepository: 角色管理和权限关联
  - PermissionRepository: 权限管理和用户权限查询
- 支持分页查询和复杂关联查询

### 3. API 层 (api crate)
- 实现认证中间件 (AuthUser extractor)
- 公开端点：用户注册、登录
- 受保护端点：用户信息查询、权限查询
- 管理员端点：用户管理、角色分配
- 集成 CORS 支持

### 4. 统一错误处理 (core crate)
- 定义 AppError 错误类型
- 自动转换为友好的 HTTP 响应
- 支持多种错误场景（认证、授权、数据库等）

### 5. 数据库迁移
- 创建 4 张核心表：users, roles, permissions, role_permissions
- 预置 3 种角色：admin, editor, viewer
- 预置 6 种权限：document:*, user:manage, system:config
- 配置角色-权限关联关系
- 修复 TIMESTAMPTZ 类型兼容性问题

## 技术细节

### 数据库
- 使用 openGauss 5.1.0（PostgreSQL 兼容）
- 采用 UUID 作为主键
- TIMESTAMPTZ 时间戳类型
- 完整的外键约束和索引

### 安全性
- Argon2 密码加密算法
- JWT token 7天有效期
- 每个请求验证用户状态
- 权限隔离验证

### 权限模型
- admin: 拥有全部 6 个权限
- editor: 拥有所有文档操作权限
- viewer: 仅拥有文档读取权限

### 受保护端点
