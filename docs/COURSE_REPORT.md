## 1. 需求分析

### 1.1 项目背景

随着远程办公和在线协作需求的日益增长，多人实时协作编辑文档已成为现代办公的重要组成部分。本项目旨在开发一款支持多人同时在线编辑文档的协作软件，实现文档的实时同步、版本控制、权限管理等核心功能。

### 1.2 功能需求

#### 1.2.1 核心功能需求

| 模块 | 功能 | 优先级 |
|------|------|--------|
| 用户管理 | 用户注册与登录 | 必做 |
| 用户管理 | 个人资料编辑 | 必做 |
| 用户管理 | 角色权限管理 | 必做 |
| 文档管理 | 文档创建与编辑 | 必做 |
| 文档管理 | 文档列表与搜索 | 必做 |
| 实时协作 | 多用户同时编辑 | 必做 |
| 实时协作 | 冲突自动处理 | 必做 |
| 实时协作 | 光标位置同步 | 必做 |
| 评论系统 | 行内评论与回复 | 必做 |
| 通知系统 | 实时消息推送 | 必做 |

### 1.4 用例表

#### UC-01 用户注册

| 项目 | 内容 |
|------|------|
| 用例名称 | 用户注册 |
| 用例编号 | UC-01 |
| 参与者 | 游客 |
| 前置条件 | 用户未登录 |
| 后置条件 | 用户账号创建成功，可以登录系统 |
| 基本流程 | 1. 用户打开注册页面<br>2. 输入邮箱、密码、昵称<br>3. 点击注册按钮<br>4. 系统验证信息合法性<br>5. 系统创建用户账号<br>6. 显示注册成功，跳转登录页 |
| 扩展流程 | 4a. 邮箱已存在：提示"该邮箱已注册"<br>4b. 密码不符合要求：提示密码规则 |

#### UC-02 用户登录

| 项目 | 内容 |
|------|------|
| 用例名称 | 用户登录 |
| 用例编号 | UC-02 |
| 参与者 | 已注册用户 |
| 前置条件 | 用户已注册 |
| 后置条件 | 用户成功登录，获得访问令牌 |
| 基本流程 | 1. 用户打开登录页面<br>2. 输入邮箱和密码<br>3. 点击登录按钮<br>4. 系统验证用户凭证<br>5. 生成 JWT 令牌<br>6. 跳转到首页 |
| 扩展流程 | 4a. 邮箱不存在：提示"用户不存在"<br>4b. 密码错误：提示"密码错误" |

#### UC-03 创建文档

| 项目 | 内容 |
|------|------|
| 用例名称 | 创建文档 |
| 用例编号 | UC-03 |
| 参与者 | 已登录用户 |
| 前置条件 | 用户已登录 |
| 后置条件 | 新文档创建成功 |
| 基本流程 | 1. 用户点击"新建文档"按钮<br>2. 选择文档类型（文档/表格/演示）<br>3. 系统创建空白文档<br>4. 跳转到编辑器页面 |

#### UC-04 实时协作编辑

| 项目 | 内容 |
|------|------|
| 用例名称 | 实时协作编辑 |
| 用例编号 | UC-04 |
| 参与者 | 文档协作者 |
| 前置条件 | 用户有文档编辑权限 |
| 后置条件 | 所有用户看到一致的文档内容 |
| 基本流程 | 1. 用户打开文档编辑器<br>2. 建立 WebSocket 连接<br>3. 接收当前文档状态<br>4. 用户进行编辑操作<br>5. 系统通过 CRDT 算法同步更改<br>6. 其他用户实时看到更新 |
| 扩展流程 | 5a. 网络断开：本地保存，重连后同步<br>5b. 编辑冲突：CRDT 自动合并 |

#### UC-05 添加评论

| 项目 | 内容 |
|------|------|
| 用例名称 | 添加评论 |
| 用例编号 | UC-05 |
| 参与者 | 文档协作者 |
| 前置条件 | 用户有文档评论权限 |
| 后置条件 | 评论添加成功，相关用户收到通知 |
| 基本流程 | 1. 用户选中文档中的内容<br>2. 点击"添加评论"<br>3. 输入评论内容<br>4. 点击提交<br>5. 系统保存评论<br>6. 向被@用户发送通知 |

#### UC-06 分享文档

| 项目 | 内容 |
|------|------|
| 用例名称 | 分享文档 |
| 用例编号 | UC-06 |
| 参与者 | 文档所有者 |
| 前置条件 | 用户是文档所有者或有分享权限 |
| 后置条件 | 指定用户获得文档访问权限 |
| 基本流程 | 1. 用户点击"分享"按钮<br>2. 输入被分享用户的邮箱<br>3. 选择权限级别（查看/评论/编辑）<br>4. 点击确认<br>5. 系统添加协作者记录<br>6. 发送通知给被分享用户 |

## 5. 系统简介

Entangle 是一款基于 Rust 全栈技术开发的多人实时协作文档编辑系统。系统采用 CRDT (Conflict-free Replicated Data Type) 算法实现多用户同时编辑时的冲突自动解决，确保所有用户看到一致的文档内容。

**核心技术特点：**

- **全栈 Rust 开发**：后端使用 Axum 高性能异步框架，前端使用 Leptos 响应式框架，实现类型安全的全栈开发体验。

- **CRDT 实时协作**：基于 yrs (Yjs Rust 实现) 的 CRDT 算法，支持多用户同时编辑，自动合并冲突操作，保证最终一致性。

- **WebSocket 实时通信**：通过 WebSocket 实现低延迟的实时数据同步，支持光标位置、在线状态的实时显示。

- **安全认证**：采用 JWT 无状态认证，密码使用 argon2 算法加密存储，保障用户账户安全。

- **openGauss 数据库**：使用国产 openGauss 数据库存储业务数据，支持复杂查询和全文搜索。

**主要功能模块：**

1. **用户管理**：支持邮箱注册登录、个人资料管理、角色权限控制。

2. **文档管理**：支持文档、表格、演示三种类型的创建与编辑，提供文件夹分类和标签管理。

3. **实时协作**：核心功能，支持多人同时编辑同一文档，实时同步内容和光标位置。

4. **评论系统**：支持行内评论、评论回复、@提及通知，方便团队沟通。

5. **通知系统**：实时推送文档变更、评论提及等通知，支持 WebSocket 即时推送。

**系统优势：**

- 高性能：Rust 语言的零成本抽象和内存安全特性带来卓越性能
- 低延迟：WebSocket + CRDT 实现毫秒级同步
- 高可靠：CRDT 算法保证数据最终一致性，无数据丢失风险
- 易扩展：模块化设计，便于后续功能扩展
